## Remediation Applied (Prioritized Recommendations 1, 2, 3, 5)

All changes are in `/home/crstio/crs-net-web/` and were verified with a fresh `docker build` + `docker run`.

### Rec 1 — Force HTTPS + HSTS (High)
- `nginx.conf`: added `map $http_cf_visitor` to read Cloudflare's client scheme, then `return 301 https://$host$request_uri` when the client used HTTP. Using `CF-Visitor` (not `$scheme`) avoids redirect loops under Cloudflare Flexible/Full.
- Added HSTS: `Strict-Transport-Security: max-age=31536000; includeSubDomains`.
- **Verified:** `curl -H 'CF-Visitor: {"scheme":"http"}'` → `301 → https://…`; HSTS header present on HTTPS responses.

### Rec 2 — Canonical host (High)
- `nginx.conf`: second `server` block redirects `www.crs-net.web.id` → `https://crs-net.web.id$request_uri`.
- `index.html`: added `<link rel="canonical" href="https://crs-net.web.id/" />`.
- **Verified:** `curl -H 'Host: www.crs-net.web.id'` → `301 → https://crs-net.web.id/`.

### Rec 3 — Real sitemap.xml (High)
- New file `sitemap.xml` (XML, lists `https://crs-net.web.id/`).
- `nginx.conf`: `location = /sitemap.xml` serves `application/xml` (single clean header).
- `Dockerfile`: copies `sitemap.xml` into the image.
- **Verified:** `GET /sitemap.xml` → `200`, `Content-Type: application/xml`, valid XML body.

### Rec 5 — Content-Security-Policy (Medium)
- `nginx.conf`: `Content-Security-Policy: default-src 'self'; script-src 'self'; style-src 'self' https://fonts.googleapis.com 'unsafe-inline'; font-src 'self' https://fonts.gstatic.com; img-src 'self' data:; connect-src 'self'; frame-ancestors 'self'; base-uri 'self'; form-action 'self'; object-src 'none'`.
- Sized to allow Google Fonts and Cloudflare's `email-decode.min.js` (already in use, so no breakage).
- **Verified:** CSP header present on HTTPS responses.

## How to Deploy
```bash
cd /home/crstio/crs-net-web
docker build -t crs-net-web .
docker run -d --name crs-net -p 8080:80 crs-net-web   # or your existing deploy
```
Then (one-time, in the Cloudflare dashboard) ensure **SSL/TLS → Edge Certificates → Always Use HTTPS** is ON, and that the DNS `A`/`AAAA` for both `crs-net.web.id` and `www.crs-net.web.id` point at the host. The container handles the actual 301s; Cloudflare's setting is a belt-and-suspenders layer.
